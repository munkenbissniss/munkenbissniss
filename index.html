Alle tre på samme maskin

Portene er valgt så ingenting kolliderer. Start Plex-stack først. Når Lydbok-stack og Musikk-stack finner den, spør veiviserne om de skal bruke nedlasterne derfra.

Da kjører det én VPN, én qBittorrent, én Usenet-klient og én Prowlarr for alt sammen. Indekserne du legger til, brukes for film, serier, lydbøker og musikk, og alt havner på samme disk.

Kom i gang

Det samme for alle tre, på Linux, macOS og Windows.

  1. Installer Docker.Docker Desktop på Windows, OrbStack eller Docker Desktop på Mac. På Linux tilbyr startskriptet å installere det for deg.
  2. Last ned og pakk ut.Knappen over gir pakken for systemet ditt.
  3. Start.Kjør start.sh, eller dobbeltklikk Start.command eller Start.bat. Veiviseren stiller noen spørsmål, og så settes alt opp.
  4. Gjør det lille som gjenstår.Oppsummeringen til slutt sier hva du må gjøre selv, som regel å legge til indeksere og lage brukere til familien.

Prosjektene er verktøy. Du er selv ansvarlig for hva du laster ned. Ikke tilknyttet Plex, Audiobookshelf, Navidrome eller appene som brukes.
